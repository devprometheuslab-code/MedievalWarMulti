# Medieval War Multi

Jeu de stratégie médiévale avec parties de 1 contre 1 à 4 contre 4, joueurs et IA, huit civilisations et un mode Campagne.

## Installation

### Android

Android 7.0 ou plus récent, appareil ARM64.

Télécharger l'APK et l'ouvrir sur le téléphone. Si Android le demande, autoriser l'installation depuis l'application qui a téléchargé le fichier.

Pour conserver les profils et la progression, installer la mise à jour sans désinstaller la version précédente. Cette version conserve l'identifiant `com.prometheuslab.medievalwar` et la clé de signature des APK précédents. L'APK utilise une compilation Release, non débogable ; la signature utilise la clé Android Debug historique du projet.

### Windows

Windows 64 bits.

Extraire le ZIP dans un dossier puis lancer `MedievalWar-0.2.5-Windows-release.exe`. Les ressources sont intégrées au jeu ; aucune installation de Godot n'est nécessaire.
